# IoT-Based Smart Helmet for Coal Miner Safety Monitoring

## 📌 Abstract
This project is designed to ensure the safety of coal miners working in hazardous underground environments. It uses ESP8266 with multiple sensors to monitor environmental and health conditions in real time.

## 🔧 Components Used
- ESP8266 (WiFi Module)
- Gas Sensor
- Temperature Sensor
- Humidity Sensor
- Vibration Sensor
- Heart Rate Sensor
- SpO₂ Sensor
- GPS Module
- Buzzer

## 📡 Features
- Real-time gas detection
- Temperature & humidity monitoring
- Vibration detection (mine safety)
- Health monitoring (heart rate & SpO₂)
- Live GPS tracking
- IoT cloud monitoring using Blynk
- Instant alert system

## 🛠️ Working Principle
The system continuously monitors environmental and physiological parameters using sensors connected to ESP8266. Data is sent to the Blynk cloud via Wi-Fi. If any abnormal condition is detected, alerts are triggered immediately.

## 🌐 IoT Platform
- Blynk Cloud

## 🎯 Applications
- Coal mining safety
- Industrial worker monitoring
- Hazardous environment tracking
